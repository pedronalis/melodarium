# Melodarium 0.1.0 — public preview

The first public preview turns a local music folder into a keyboard-friendly library, plays it
through libmpv and keeps collections, tags, listening history and podcasts in a local SQLite
database. There is no account, cloud library or telemetry.

This release includes an x86_64 Flatpak bundle and SHA-256 checksum. It was built from the tagged
source by GitHub Actions and carries a GitHub artifact-provenance attestation.

```bash
sha256sum -c melodarium-v0.1.0-x86_64.flatpak.sha256
gh attestation verify melodarium-v0.1.0-x86_64.flatpak \
  --repo pedronalis/melodarium
flatpak install --user ./melodarium-v0.1.0-x86_64.flatpak
```

Highlights:

- local music organized by tracks, artists, albums, genres, tags and smart views;
- lossless-aware libmpv playback, persistent editable queue, MPRIS and media keys;
- RSS podcasts with downloads, per-episode resume, retention and OPML portability;
- ordered collections, M3U export and validated backup/restore bundles;
- Fedora CI with 35+ test targets, QML lint and deterministic visual/interaction gates.

Known limits: Linux is the only tested platform; the interface is currently pt-BR; this is not a
Flathub listing; the Flatpak does not bundle `yt-dlp`; and the downloadable bundle is not signed by
a long-lived project key. Verify both its checksum and GitHub attestation.

# Melodarium 0.1.0 — preview público

O primeiro preview público transforma uma pasta local de música numa biblioteca navegável pelo
teclado, reproduz tudo pelo libmpv e mantém coleções, tags, histórico e podcasts num banco SQLite
local. Não há conta, biblioteca na nuvem nem telemetria.

Esta release inclui um bundle Flatpak x86_64 e seu checksum SHA-256. Ele foi construído a partir da
tag pelo GitHub Actions e recebe um atestado GitHub de proveniência do artefato.

Destaques:

- música local por faixas, artistas, álbuns, gêneros, tags e visões inteligentes;
- reprodução libmpv consciente de lossless, fila persistente/editável, MPRIS e teclas de mídia;
- podcasts RSS com downloads, retomada por episódio, retenção e portabilidade OPML;
- coleções ordenadas, exportação M3U e bundles validados de backup/restauração;
- CI Fedora com 35+ alvos de teste, lint QML e gates determinísticos visuais/de interação.

Limites conhecidos: Linux é a única plataforma testada; a interface está em pt-BR; isto não é uma
listagem no Flathub; o Flatpak não inclui `yt-dlp`; e o bundle não é assinado por uma chave duradoura
do projeto. Verifique tanto o checksum quanto o atestado do GitHub.
